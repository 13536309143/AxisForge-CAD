# 配合可视化、场景点选与自适应地板

适用版本：AxisForge CAD 0.4.0。日期：2026-11-12。

## 选中配合后看什么

在左侧“配合关系”页单击一条关系，三维场景会突出显示参与模型：基准 A 为青色，从动 B 为橙色。左上角说明配合类型、启用与满足状态、对象名称和局部轴。

| 配合 | 场景中的标记 | 几何含义 |
| --- | --- | --- |
| 同轴 | A/B 轴线、原点十字、共用轴线提示 | 局部轴变换到世界后共线，保留轴向滑动和绕轴转动 |
| 平行 | 分别经过两对象原点的轴线、双短线符号 | 平行与反平行均满足，不约束位置 |
| 垂直 | 两根模型轴、共同顶点的方向弧与 90° 标注 | 只约束两轴方向正交 |
| 中心距离 | 原点之间的尺寸线、端部刻线／箭头、当前值与设定值 | 两对象原点的欧氏距离 |
| 原点重合 | 原点十字、连接及偏差值 | 两原点同位，保留姿态自由 |
| 指定夹角 | 轴线、角度弧、当前角度／设定角度 | 两根有向轴的 0～180° 夹角 |
| 沿轴偏移 | A 轴、B 原点到 A 轴的投影辅助线、有符号距离 | B−A 在 A 所选正向轴上的投影 |

垂直和指定夹角可能使用位置互不相交的两根轴，所以角度示意将方向平移到共同顶点，用虚线引回原对象，并标注“方向示意（平移至共同顶点）”。它不声称模型轴在空间中实际相交。

标记置顶绘制，穿过实体时仍可看到，用于观察配合，不能作为隐藏线工程图。标签在视口内摆放并尽量避开说明卡片；超出相机范围的线段会裁剪。标记不修改模型颜色，不改变实体拓扑、网格数量或撤销历史，也不会为每次选择重新上传模型缓冲。

停用关系采用灰色虚线与“已停用”状态，仍可检查当前关系，不会把其显示为已求解。若参与对象隐藏，会说明原因并隐藏几何标记；选择其他模型、删除关系或替换项目后，旧标记会清除或按有效 ID 更新。

## 添加和编辑配合

1. 通过工具栏“添加配合…”、装配菜单或 `Ctrl+M` 打开编辑器。
2. 从下拉框选择 A 与 B，或点击“场景点选 A → B”，在视口依次点击两个对象。
3. 也可用“选 A”“选 B”单独替换对象，用“交换 A/B”改变驱动方向。A 和 B 不能是同一对象。
4. 选择配合类型、局部 X/Y/Z 轴，以及当前类型需要的距离、角度或偏移。无关参数会禁用。
5. 默认实时预览位置与姿态，视口明确提示“尚未应用”。取消勾选预览时只显示当前几何关系，应用时仍会重新求解。
6. 点击“应用配合”，通过求解后形成一个撤销步骤并选中该关系；失败保留原文档并显示原因。

窗口为非模态，可以保持打开并旋转、缩放或平移场景。编辑期间视口左键只选择对象，不拖动模型，避免把临时预览状态写入文档。`Esc` 在视口取消点选；编辑器自身的取消按钮关闭预览。若预览使两个对象重叠不便点选，可先取消勾选实时预览，完成 A/B 选择后再开启。

编辑已有配合可双击关系，或选中后按“编辑”／`Ctrl+Shift+M`。原 ID 保留，修改可撤销／重做。关系页 `Delete` 删除所选配合，不删除模型。

预览仅在候选场景中进行，不创建撤销记录。关闭或取消恢复当前文档的实际状态；预览期间若另有正常编辑，取消不会撤销那些编辑。对象或原配合被删除后，编辑器会更新引用、提示失效并禁止应用，不会悄悄恢复已经删除的数据。视角调整属于查看操作，不随预览取消恢复。

## 三种新增关系的使用示例

### 原点重合

把 A 固定，设置 B 与 A 原点重合。求解令 `pB = pA`，B 的姿态保持其他关系允许的状态。该关系不表示两个任意选择的表面接触，也不执行碰撞检查。

### 指定夹角

选 A 的 Z 与 B 的 Z，输入 45°，B 转动至两轴夹角 45°，位置不因此改变。角度使用有向轴：0° 同向，180° 反向，90° 正交。它与包含反平行的“平行”关系具有不同方向语义。

### 同轴加沿轴偏移

先建立 A.Z 与 B.Z 同轴，再建立从 A 指向 B 的沿轴偏移，例如 +50 mm。同轴消除径向偏移并对齐轴，轴向偏移将 B 原点定位在 A 原点沿 A.Z 正向 50 mm 处；−50 mm 位于反向。

沿轴偏移单独使用时只约束投影：`dot(pB−pA, axisA) = offset`，保留径向位置和姿态。因此它不是单独就能令两个对象同轴的关系。

## 求解和文件兼容

所有配合仍按“源 A → 目标 B”的有向无环图传播。闭环、固定目标冲突或不能收敛的组合会拒绝并回滚。新增关系没有把求解器变成通用工业装配求解器，也没有引入面／边的持久引用。基准仍是对象原点与局部轴。

含三种新增关系的项目写为 `.afcad` version 4。角度以度保存，偏移以 mm 保存。当前程序兼容 version 1～4：仅原有实体和关系仍保存 version 2；含网格但没有新关系时仍为 version 3。旧程序不能读取 version 4，请用 0.4.0 或更新版本继续编辑。

角度关系使用稳定的 `atan2(|u×v|, u·v)` 检查实际角度，避免 0°／180° 附近直接 `acos` 放大浮点误差；角度残差按弧度与阈值比较。其余关系继续使用原有线性或方向残差定义。

## 地板怎样自适应

地板覆盖可见模型的世界空间范围，并结合相机目标和查看距离留出余量。模型放大、移动到远处、旋转、隐藏或导入新对象后，会据当前范围重新计算。世界范围由局部几何包围盒的变换角点计算，不依赖显示网格恰好采样到某个极值。

间距采用 1、2、5 × 10ⁿ mm，自动从细网格过渡到粗网格；每五格用较亮的主线。视口左上角显示当前间距。网格线数量保持在有限范围，大模型不会生成数百万条线；相机缩放／平移只在网格方案变化时更新地板缓冲，复用模型缓冲。

地板高度位于世界 Z=0 或可见模型最低处之下，并有很小的显示偏移，避免与底面完全重合。坐标轴仍表达世界坐标原点。地板是显示辅助，不作为可选模型，不参加配合、布尔或文件导出。

同时扩大了适配视图／滚轮缩放的距离范围，并随相机与场景调整近远裁剪面，改善大型场景的覆盖与深度精度。极端坐标下仍受浮点显示精度和图形硬件限制。

## 验证与复现

核心回归覆盖新增配合、0°／180° 邻域、同轴加偏移、冲突回滚、version 4 往返、七种标记、停用／隐藏／失效引用、大型旋转模型的网格覆盖与密度上限。

桌面检查通过真实选择事件验证 A→B 点选，并检查预览不修改文档、取消无历史、一次应用一个撤销步骤、原 ID 编辑、撤销更新标记、删除引用的安全处理、七类实际截图和大模型地板。

复现命令：

```powershell
ctest --test-dir build -C Release --output-on-failure
```

具体数量、环境与自动构建结果见 `TESTING.md` 和对应提交的 GitHub Actions。
