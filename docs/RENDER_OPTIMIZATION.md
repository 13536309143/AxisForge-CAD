# LOD 与视锥剔除

2026-11-17，随 1.0.1 发布；v1.0.0 标签与附件保持不变。

## 使用

在底部“场景统计”中使用“自动 LOD”和“视锥剔除”两个复选框，默认开启。关闭后可对照同一视角的提交数量。设置只影响当前视口，不写入项目文件。

统计新增上一绘制帧的绘制实例、剔除实例、实际提交表面三角形和高／中／低 LOD 实例数。原来的总数／可见数仍按原始完整网格统计；“可见”是对象可见属性，不代表位于视锥内。LOD 计数表示选择的档位，简单实体各档三角形数可能一样。线框和包围盒模式不提交表面三角形，数字为零是正常的。

## 三档实体 LOD

对 B-Rep 实体预生成完整／半细分／四分之一细分三档，最低细分8。使用独立复制的 OCCT shape 重新离散，避免改变原始实体、拾取网格和导出数据。若低档没有减少三角形或生成失败，回退到上一档。

按投影包围球直径选择档位，使用逻辑像素阈值：高档退出160px、进入200px，低档进入64px、退出88px。滞回减少轻微缩放时的往复切换，不提供连续几何渐变。透视下使用保守的最近深度估计，靠近或跨越眼平面的对象保持高精度；支持正交视图。

仅常规模式自动降低精度；选中模型和当前配合涉及的模型保持完整精度，三角面／线框／包围盒模式使用原始诊断数据。导入的 GLB/OBJ 网格当前保留完整网格，不做可能破坏边界和外观的简化。后续可接入专门的网格简化器。

LOD 减少每帧表面三角形提交，但预生成和额外 GPU 数据会增加初次加载成本与缓冲占用。当前没有声明任意场景 FPS 提升倍数。

## 视锥剔除

使用每个对象局部包围盒的八个角点，经 P×V×M 转换到齐次裁剪空间。只有所有角点都在同一裁剪平面之外才跳过对象，覆盖左右、上下、近远六个面。相交或包围相机的边界保守保留，不使用透视除法，避免相机后方 w 为负时的误判。

此处是 CPU 对象级视锥剔除，不是遮挡剔除或三角形级剔除。地板和二维辅助标注仍由各自路径绘制。关闭可见属性的对象不计入视锥剔除数。不会删除对象、变更配合或减少导出内容。

## 缓存

场景更新时按对象 ID 和不可变 SolidData 指针复用已有 GPU 网格。仅颜色、位姿改变通常不再重新生成／上传三档；几何变化才重新建立该对象的网格。删除对象、清空场景与上下文销毁仍释放相应资源。

## 验证

本机 Windows x64、Qt5.15.2、MSVC19.44、OCCT7.9.3 完成 Release 构建，CTest 3/3通过。新增核心检查覆盖六个面、相交边界、透视前后方、包围相机及 LOD 滞回。新增桌面检查覆盖远处减面、选中保真、LOD关闭、剔除开关和实际 framebuffer 绘制。既有拾取、拖动、配合、显示模式与缓冲稳定检查也通过。

不等于完成大型装配压力测试、全硬件验证或 GPU 性能基准。
