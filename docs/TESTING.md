## 复现

```powershell
ctest --test-dir build -C Release --output-on-failure
build/Release/AxisForgeCAD.exe --self-test build/test-artifacts
```

将对应Qt运行库放到可执行程序旁或正确配置PATH和平台插件路径。打包版还提供 `test.cmd`，会运行随包附带的核心测试和桌面自检。

产物包括 `desktop-test.json`、`workbench.png`、往返项目、OBJ与STL。核心断言在Release中也执行，不依赖会被优化关闭的标准assert。

## 范围限制

本次未在本机验证Qt 6/Linux/macOS，也没有执行百万三角形压力、长时间稳定性、复杂闭环装配或多显示器DPI测试。仓库CI配置与实际远程运行结果分开报告。输入事件自检不是完整人工操作验收，颜色像素检查也不能证明每个表面和遮挡都正确。
