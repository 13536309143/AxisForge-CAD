## 复现

```powershell
ctest --test-dir build -C Release --output-on-failure
```

运行包用test.cmd执行独立核心测试与两种桌面模式。FPS检查需要窗口实际显示，隐藏/最小化时无正常呈现事件。短时FPS样本不作为正式性能基准。

## 边界

核心按层级装配求解，不支持闭环；STEP实例展开，不保留可编辑装配层级、面级多色、PMI或外部引用；B-Rep布尔是独立快照，不是完整特征历史。未对任意复杂生产模型或恶意几何进行全面压力测试。
