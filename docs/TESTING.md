## 正式发布流水线

Linux Qt6 / OCCT7.6 在 Ubuntu24.04、Xvfb与软件图形栈执行全部CTest。Windows Qt6.8.3 / OCCT7.9.3独立配置、编译、部署运行库，再执行运行包内核心测试。两项成功后才生成GitHubRelease，并附Windows ZIP、当前提交源码ZIP和SHA256SUMS。

对应发布提交的最终状态以GitHub Actions记录为准。Windows runner未用于宣称真实硬件图形性能或完整桌面验证；Windows桌面结果来自上述本机Qt5环境。

## 复现

在配置了运行库、插件和资源的开发环境运行：

```powershell
ctest --test-dir build -C Release --output-on-failure
```

也可在完整运行包中运行test.cmd。Linux无显示器可使用LIBGL_ALWAYS_SOFTWARE=1与xvfb-run。帧事件检查需窗口实际呈现，隐藏/最小化或远程图形环境可能改变结果；短时FPS不作为正式性能基准。
