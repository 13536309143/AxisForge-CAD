# OCCT 集成测试报告

版本：0.2.0；本机日期：2026-11-12。

## 本地环境

Windows x64、MSVC 19.44、Qt 5.15.2、OCCT 7.9.3、NVIDIA RTX 3060 / OpenGL 3.3。
OCCT开发包SHA256：`2a4f5e187992427674869e89477882d1ace4d67695d4b27173830d93f8cf11be`，与官方发布资源digest一致。

## 结果

- 核心回归：49通过，0失败。
- CTest：核心、VSync ON桌面、VSync OFF桌面，3/3通过。
- 每种桌面自检：58项检查通过。

## 几何验证

五种OCCT实体的拓扑、法线、三角形绕序与近似网格体积；精确体积与面积；布尔并/差/交的解析体积；长方体减圆柱的真实通孔；带旋转和平移的布尔；无交集、完全相减与同对象操作拒绝；不连接实体并集保留多个solid；B-Rep压缩保存重载后继续布尔；坏载荷拒绝；v1项目兼容。

## STEP验证

中文路径和名称；多个零件的名称、颜色与位置往返；布尔实体往返保持体积；隐藏对象不导出；空导出失败；错误文件不覆盖现有数据；嵌套装配的重复实例和组合位姿；源文件米单位换算到项目毫米。

## 桌面验证

原有创建、删除、拖动、约束传播、撤销、属性面板重开、场景统计、内存和真实帧事件检查；追加布尔动作、隐藏原对象、通孔精确体积、撤销/重做、实体参数只读、项目磁盘重载、STEP导入导出与导入撤销。

## 复现

```powershell
ctest --test-dir build -C Release --output-on-failure
```

运行包用test.cmd执行独立核心测试与两种桌面模式。FPS检查需要窗口实际显示，隐藏/最小化时无正常呈现事件。短时FPS样本不作为正式性能基准。

## 边界

核心按层级装配求解，不支持闭环；STEP实例展开，不保留可编辑装配层级、面级多色、PMI或外部引用；B-Rep布尔是独立快照，不是完整特征历史。未对任意复杂生产模型或恶意几何进行全面压力测试。
