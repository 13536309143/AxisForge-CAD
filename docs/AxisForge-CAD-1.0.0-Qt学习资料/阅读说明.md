# 配套 Qt 学习练习

先阅读同级的《AxisForge CAD 1.0.0：项目详解与 Qt 实战学习手册》HTML。

## 两个工程

- `QtWidgetsLab`：纯 Qt Widgets，练习布局、信号连接、动作、停靠面板、列表选择、参数编辑、JSON 安全保存与校验读取。不含三维几何和撤销功能。
- `QtGLTriangle`：Qt + OpenGL 3.3 Core，练习上下文、VAO/VBO、GLSL、绘制和清理，不依赖 OCCT。

两者独立构建，支持 Qt5/Qt6 的 CMake 查找。实际验证环境为 Windows x64、MSVC 19.44、Qt 5.15.2；本资料包未额外验证 Qt6 与 Linux 上的练习运行。

## Windows 构建

Developer PowerShell 切换到所选工程目录，把下列 Qt 路径改为实际匹配 MSVC x64 的 SDK：

```powershell
cmake -S . -B build -G 'Visual Studio 17 2022' -A x64 -DCMAKE_PREFIX_PATH=C:/Qt/6.8.3/msvc2022_64
cmake --build build --config Release
C:\Qt\6.8.3\msvc2022_64\bin\windeployqt.exe --release build\Release\QtWidgetsLab.exe
.\build\Release\QtWidgetsLab.exe
```

三角形工程将目标名替换为 `QtGLTriangle`。使用 Qt5 时，同时替换 CMake 前缀与部署工具路径。Qt Creator 可直接打开各自的 CMakeLists.txt，选择匹配 Kit。

## 自动检查

```powershell
.\build\Release\QtWidgetsLab.exe --self-test
# 在另一个工程目录：
.\build\Release\QtGLTriangle.exe --self-test
```

第一个检查实际控件操作、14 个断言、JSON 往返与无效载入保护。第二个检查绘制就绪、framebuffer 与中心区域颜色。均需要可用显示环境；三角形还需要 OpenGL 3.3 Core。成功退出码为 0。它们不代表完整 GUI 自动化、任意文件安全验证或显卡性能基准。

练习允许直接打开文件替换当前列表，没有 CAD 主工程的未保存修改提示和撤销机制。可以把这两项作为学习任务补上。
