# 创建前设置建模参数（1.0.2）

点击模型按钮、菜单或相应快捷键后，先显示参数窗口。确认“创建模型”才向场景加入对象；取消不修改场景，不新增撤销记录。参数非法时显示原因，保留窗口供修改。确认创建、撤销或重做均按一个操作处理。

| 模型 | 建模参数 | 细分 |
| --- | --- | --- |
| 长方体 | 长度 X、宽度 Y、高度 Z | 不显示 |
| 球体 | 半径 | 曲面细分 |
| 圆柱 | 半径、高度 | 曲面细分 |
| 圆锥 | 底面半径、高度 | 曲面细分 |
| 圆环 | 主半径、次半径（管半径） | 曲面细分 |
| 圆管 | 外半径、内半径、高度 | 曲面细分 |
| 圆台 | 底半径、顶半径、高度 | 曲面细分 |
| 椭球 | X/Y/Z 方向直径 | 曲面细分 |
| 楔形体 | 长度 X、宽度 Y、高度 Z | 不显示 |

所有长度单位为 mm，范围 0.1～10000。曲面细分范围 8～128，影响显示离散化；精确实体仍按尺寸参数构建。圆环次半径小于主半径，圆管内半径小于外半径，当前圆台顶半径小于底半径。

每个窗口还可设置名称。创建后右侧检查器使用相同参数定义，只显示所选类型的相关字段及相应名称。导入网格和冻结实体不提供基本图元参数编辑；它们仍可编辑名称、颜色和位姿。

项目统一采用格式8，仅读取当前格式。本轮测试覆盖九种窗口的字段组合、取消不改场景或历史、非法参数保留窗口、实际传入尺寸/名称/细分、单步撤销以及检查器字段隐藏。
