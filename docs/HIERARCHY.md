# 模型树与父子装配

适用正式版本1.0.2。

## 使用

1. 在“模型树”菜单或模型树右键菜单选择“新建根空节点”。空节点没有几何，可作为装配坐标和配合基准。
2. 选中节点后可“新增子空节点”。选中空节点创建基本模型时，新模型自动挂在该空节点下。
3. 把现有模型拖放到目标节点上，或选择“设置父节点…”。挂接和脱离保留当前世界位置／旋转；选择“移到场景根节点”可解除父子关系。
4. 在属性面板修改父节点的位置／旋转，所有后代一起变换。选中一个空节点，再在视口拖动它的后代几何，可拖动整个子树；Esc取消，一次拖动只产生一步撤销。
5. 菜单“示例 → 轴承（层级装配）”可直接体验。总装含内外圈、滚珠组、保持架组，展开树后可分别选择。

拖到一行上表示成为其子节点；拖到行与行之间表示挂到该行的父节点，不保证持久化同级排序。根、普通模型和空节点都能有子节点。空节点单独没有可拾取面，先从树中选择。

## 约束继承的含义

父节点的配合驱动其位姿，整个子树随父节点平移／旋转，保持子节点相对父节点的位姿。不会把同轴、距离等约束复制到每个子节点，否则会错误地把所有子节点拉到同一个轴或中心。

子节点可以独立改变相对位姿，也可有自己的配合；自身配合可能调整其继承后的位姿。父子关系不是把所有后代焊成不可编辑的一件实体。固定阻止对象自身被配合或拖动驱动，但对象仍跟随祖先运动；它不是对子树每个节点设置世界锁定。

配合依赖与父子依赖一起进行排序，循环或无法满足的关系被拒绝并回滚。地面对齐用于空节点时，以整个子树几何的最低世界Z为准；没有几何的空子树不能贴地。

## 操作与数据

- 子树整体复制；新ID、父子引用及内部配合重新映射，外部配合不复制。
- 删除节点会删除整个子树及引用这些节点的配合；撤销恢复全部内容。
- 隐藏父节点会隐藏后代；子节点自身的可见开关保留，重新显示父节点时生效。
- 模型树显示全部节点；场景统计的渲染实例只统计有几何的模型，空节点不分配模型GPU缓冲。
- LOD、拾取和导出使用完整世界位姿。选中父节点或其配合时，后代几何一起高亮。
- 属性中的位置／旋转仍是世界坐标；内部保留世界位姿缓存，在编辑／求解时按父节点的刚体增量传播，效果等价于组合局部位姿。不是QObject控件父子关系或C++类继承。

## 保存格式

所有 `.afcad` 统一写为格式8，parentId必须显式存在，位置／四元数为世界位姿。只读取当前格式，不兼容或迁移旧格式。保存失败、无效父节点、父子循环会拒绝，不留下部分修改。

STEP、GLB、OBJ、STL在本次实现中仍按可见几何的世界位姿展开，不保留本软件空节点树或配合；需要继续编辑层级请保存 `.afcad`。
